# Python Password Strength Checker

## Project Overview 
This project is a Python program that evaluates password strength and provides feedback to users.
## Features 
-Checks password length and complexity 
-Validates uppercase, lowercase, numbers, and special characters
-Provides feedback on weak passwords 
-Hides password input using getpass

## Tools & Technologies 
-Python 3
-string and getpass modules

## How to run
Run the following command:

```bash
python3 passwordStrengther.py
```
